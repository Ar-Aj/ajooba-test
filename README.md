# ajooba-test

Ajooba Footwear monorepo (`pnpm` workspace):

- `apps/storefront` — Customer e-commerce storefront (Next.js 16, Port `3000`)
- `apps/admin` — Operations & catalogue admin console (Next.js 16, Port `3001`)
- `apps/api` — Express 5 + MongoDB backend API (Port `4000`)
- `packages/contracts` — Shared Zod schemas and TypeScript contracts
